T-01 Critical Keamanan app/Http/Controllers/Api/BusinessApiController.php:97 BOLA (Broken Object Level Authorization) & Bypass Approval Hapus Tender via REST API. Endpoint DELETE /api/tenders/{tender} menghapus tender tanpa pengecekan hak akses atau alur izin Owner/Manager. User dengan token API biasa dapat menghapus tender manapun secara sepihak tanpa melewati alur persetujuan dua pihak. Terapkan middleware role/permission pada route API dan integrasikan alur request-deletion yang sama dengan web controller. Code Review Logika Kritis Terverifikasi
T-02 Critical Keamanan app/Http/Controllers/Api/BusinessApiController.php:80 Bypass Alur Persetujuan Perubahan Harga Produk & Kontrak via API. Endpoint PUT /api/products/{id} dan PUT /api/contracts/{id} mengubah harga secara langsung tanpa permohonan ke Manager. Pencegahan perubahan harga sepihak yang diatur di web diabaikan melalui API, membuka celah manipulasi finansial. Tambahkan otorisasi strictly role:owner,manager pada aksi mutasi harga di BusinessApiController. Code Review Logika Kritis Terverifikasi
T-03 High Keamanan app/Http/Controllers/TenderController.php:438 Unrestricted File Upload pada Dokumen Tender. Validasi hanya 'required|file|max:10240' tanpa pembatasan ekstensi atau MIME type (mimes:pdf,docx,xlsx,png,jpg). Penyerang dapat mengunggah file berbahaya (.php, .html, .svg) ke direktori public storage, berpotensi Remote Code Execution (RCE) atau Stored XSS. Tambahkan validasi ketat: 'mimes:pdf,doc,docx,xls,xlsx,jpg,jpeg,png' dan simpan file di storage non-public dengan download berotorisasi. Code Review Logika Kritis Terverifikasi
T-04 High Bug app/Services/SalesService.php:20 Race Condition Validasi & Pengurangan Stok Barang. Pengecekan stok $product->stock tidak menggunakan lock baris (lockForUpdate). Dua transaksi serentak pada stok produk yang sama dapat lolos validasi bersamaan, menyebabkan kuantitas stok di gudang menjadi negatif. Gunakan Product::where('id', $id)->lockForUpdate()->firstOrFail() di dalam transaksi DB sebelum validasi kuantitas. Code Review Logika Kritis Terverifikasi
T-05 High Keamanan app/Http/Controllers/AuthController.php:189 Ekspos Tautan Reset Password Beserta Token pada Session/Response di Environment local/testing. Jika aplikasi dijalankan di server staging publik dengan APP_ENV=local, token reset password terekspos sehingga akun dapat diambil alih tanpa akses email. Hapus pengembalian reset_url di session response atau batasi strictly hanya jika running di PHPUnit unit test context. Code Review Logika Kritis Terverifikasi
T-06 Medium Bug app/Services/SalesService.php:40 Penomoran Penjualan dan Invoice Lemah Menggunakan rand(100, 999). Ruang acak hanya 900 kombinasi per hari. Dalam volume penjualan padat, collision pada unique constraint akan melempar unhandled QueryException dan memicu HTTP 500. Gunakan auto-increment sequence harian, atomic counter di database/redis, atau format berbasis UUID/timestamp mikrodetik. Code Review Logika Kritis Terverifikasi
T-07 Medium Bug app/Http/Controllers/ServiceOperationsController.php:137 Permintaan Material Operasional Jasa Mengurangi Stok Gudang Tanpa Pengecekan Ketersediaan. Jika stok produk di dagang lebih kecil dari permintaan teknisi jasa, stok barang langsung berkurang menjadi negatif tanpa error atau peringatan. Tambahkan validasi ketersediaan stok fisik sebelum membuat StockMovement OUT. Code Review Logika Kritis Terverifikasi
T-08 Medium Keamanan routes/web.php:52 Exemption CSRF pada Logout Route dan Penggunaan HTTP GET. URL /logout dapat diakses via GET dan dikecualikan di VerifyCsrfToken. T-09 Medium Bug app/Services/PaymentService.php:15 Ketiadaan Pessimistic Locking pada Pengecekan Overpayment Invoice. T-10 Medium Performa app/Models/Product.php:39 N+1 Query Issue Akibat Appended Accessor 'stock' pada Model Product. $appends = ['stock'] mengeksekusi 3 query terpisah per row jika relasi tidak di-preload. No Aspek / Modul Kendala yang Ditemui Penyebab Teknis Dampak pada Pengujian
1 Eksekusi Feature Tests 14 dari 15 test gagal dieksekusi saat 'php artisan test' dijalankan. PHP CLI 8.1.10 pada Laragon belum mengaktifkan ekstensi pdo_sqlite, sedangkan phpunit.xml mengarahkan koneksi ke SQLite In-Memory. Pengujian integrasi otomatis tidak dapat memvalidasi alur bisnis secara dinamis; pengujian dikompensasi via code review mendalam.
2 Dynamic Code Coverage Profiling Tidak dapat menghasilkan laporan persentase line/branch coverage real-time. Ekstensi driver coverage (Xdebug atau PCOV) tidak terpasang di runtime PHP CLI lokal. Cakupan pengujian (coverage) dilaporkan berdasarkan ketiadaan tes fungsional yang lulus pada modul-modul bersangkutan.
3 Aturan Ketat Non-Mutasi Kode Tidak diperkenankan mengubah phpunit.xml atau mengaktifkan ekstensi host. Aturan Strict Rule 1 & Rule 7 melarang modifikasi kode atau file konfigurasi proyek, serta melarang 'memperbaiki' kegagalan test. Kondisi dilaporkan secara objektif dan faktual apa adanya dalam laporan QA.
4 Audit Secret di History Git Analisis riwayat git commits terbatas pada shallow clone lokal. Repositori lokal berada di direktori SignalNiagaJasaTender dan sebagian file log tidak dimasukkan ke version control. Pemindaian kredensial difokuskan pada file konfigurasi (.env, config/) dan tree kode sumber aktif.
